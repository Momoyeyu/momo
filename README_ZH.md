# momo

一款以相处、记忆和共同成长为核心的 AI 游戏。

你可以用文字或语音与 momo 交流，看她随着对白切换表情和动作，回顾共同经历，并通过可信的拓展让她做到更多事情。她的核心人格保持稳定，相处方式和经历逐渐积累。
