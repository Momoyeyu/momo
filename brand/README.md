# momo visual identity

Original vector artwork for momo. The mark uses asymmetric cut-paper silhouettes and negative space: a loose suggestion of a presence, without a fixed character, eyes, mouth or facial expression. The wordmark uses rounded hand-shaped strokes and a small tapered cut echo.

The palette is shared with the game: ink purple `#18151F`, soft gold `#E7BE77`, warm white `#F3ECDF`. AIRI was inspected only for the principle of an independent silhouette identity; no AIRI artwork, outlines or font tracing are incorporated.

These are the source SVGs. Application/site copies must remain byte-identical. Generate native platform icons from `momo-icon.svg`; the brand remains independent of any selected Live2D avatar.
