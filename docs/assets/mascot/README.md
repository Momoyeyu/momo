使用内置 `image_gen` 生成；A 经同一工具修订。模型版本由工具管理，未暴露具体版本。生成输入没有第三方角色原图，不依赖 Claude / GPT / DeepSeek / AIRI 的人物素材。

原始 PNG 保留 RGBA；应用与官网使用无损 WebP，alpha 与可见像素一致；已在深 / 浅底逐像素核对。完全透明像素仍可能带底色 RGB，实际绘制和 mask 以 alpha 为准，不应丢弃 alpha 直接使用 RGB。没有用后期自动抠图改变人物边缘。

配色：墨紫 `#18151F`、灰紫 `#49414D` / `#B7AEBD`、柔金 `#E7BE77`、暖白 `#F3ECDF`。靠轮廓、负形与大色块表达；纸纹与抗锯齿保留少量色差。

官网本轮只使用 C：金 / 墨紫 / 暖白的大块内部反差，不使用自然肤色。一次采样成三种墨色与字符，像素流转后交给真实对话。README / 游戏中的 A 仍是上一轮未验收候选，本轮没有重复替换应用或构建安装包；统一适配等美术方向 review 后推进。抽象标记、字标和默认 Hiyori 保留。

本轮核对了 [ZipZipPipe 的整组原作](https://www.pixiv.net/artworks/148186519)，以 Grok 的明亮长发与黑金哥特反差作气质参考；没有沿用其双马尾、冠饰、翼或战斧。参考视频的三色剪影由影片作者另行制作，其人物、截图、音乐与代码没有进入正式资源。研究图只保存在忽略的本地目录。
