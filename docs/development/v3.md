本轮候选的共享源固定为 `7cac33ebb163302be03632c8b700a9823bea217e`。`app/migration/web-source.json` 记录 564 个受管文件、来源与 SHA-256；首次晋级清退六个旧存档组件。后续从 Web 的 `scripts/promote.py` dry-run 后应用，目标漂移或本地修改则拒绝，相同 revision 再次晋级没有 diff。Tauri 与发行文件不受共享晋级覆盖。

## 当前行为与验证

只有一段持续关系，永久账本、展示 / 送达 ACK、近期上下文与长期记忆分开。Python 是唯一协调器，Cordis 是随包 Node 承载的常驻能力宿主；面对面租约在设置 / 历史仍保留，回标题才结束。真实消息平台与游戏能力留后续计划。

Web 回归与独立复审通过；最终共享快照的 macOS 原生 E2E 4 项通过，断网冻结包验证真实 E5 / sqlite-vec、SenseVoice / VAD、Core / soul、随包 Node、单实例与退出回收。Windows 和本轮真实 TTS 未验证。详细分层结果见 [Web 验证记录](https://github.com/Momoyeyu/momo-web/blob/v3/development/docs/development/v3-verification.md)。

macOS 测试包 identifier 为 `dev.momo.app.v3smoke`，与现有安装隔离。它不是正式发行版；维护者体验认可后才决定合并和发行。用户数据、供应商密钥和测试录音不进入源码 / 安装资源。下个高优先级议题为上下文管理，需与维护者共同确认机制。

## 构建

先按 [资源准备流程](migration.md#从干净源码构建) 准备锁定的离线模型与 Core，安装锁定的 `app/backend` / `app/frontend` / `app/plugin-host` 依赖及 PyInstaller 6.20.0，再执行：

```sh
pnpm --dir app build:plugin-host
pnpm --dir app build:backend
pnpm --dir app build:e2e
pnpm --dir app test:native
```

宿主准备脚本校验固定 Node 22.23.3 的上游归档哈希，只打包生产依赖和宿主源码。发行包应走已有正式构建流程；E2E 包包含测试驱动，不作为正式下载。
