# momo v0.2.0 · Can you feel my heart?

第一次相遇，从一句问候开始。这一版将早期实验整合成可以安装的桌面应用：有形象、有声音，也能留下共同经历的 AI 伙伴。

## 这一版可以体验什么

- **第一次相遇**：momo 主动询问称呼，形成初始记忆；引导只运行一次。首次连接会实际验证模型能否回答，失败时保留配置草稿并说明原因。
- **延续的性格与记忆**：稳定的 soul、长期记忆与内置语义检索。记忆可以查看、编辑或删除，对话回顾和存读档保留相处进度。
- **会回应的形象**：Live2D 表情、动作与字幕 / 语音的演出控制；形象配置中可以预览、调整绑定，并查看播放进度。
- **文字与声音**：随安装包提供语音识别与 embedding 资源，无需首次下载模型。可选接入 GPT-SoVITS 并自行提供参考音；支持播放、打断和回放。
- **你的模型与工具**：配置兼容 OpenAI 格式的模型 API；原生 thinking 默认关闭，支持的服务可手动开启，思考内容不显示或朗读。MCP 拓展可连接你信任的工具。
- **桌面体验**：中文 / English / 日本語、启动动画、统一剪影与玻璃菜单。标题进入房间时用 ASCII 粒子交接，设置 / 存档返回保留原有转场，并修正对话框的入场时序。
- **本地数据**：备份和恢复配置、记忆、对话及导入资源；单实例运行，退出回收本应用自己的后端进程。

未来的自主进化、自动扩展能力和原创 Live2D 建模仍是探索方向，本版不包含这些承诺。

## 下载与安装

| 安装包 | 本次验证范围 |
| --- | --- |
| `momo_0.2.0_macos_arm64.dmg` | macOS 14+，Apple Silicon；真实 macOS 安装与交互验证 |
| `momo_0.2.0_windows_x64_setup.exe` | Windows x64，Windows 11 实机安装与交互验证 |

下载后可对照同页 `SHA256SUMS.txt` 校验。`build-info.json` 记录版本、源码提交和产物摘要。

**macOS**：打开 DMG，将 momo 拖入 Applications 后启动。当前包为 ad-hoc 签名，未获 Apple Developer ID 签名 / 公证；系统可能阻止首次打开。核对来源与校验值后，按「系统设置 → 隐私与安全性」中的单个应用打开提示操作，无需关闭全局安全保护。仅提供 Apple Silicon 包，不提供 Intel 包。

**Windows**：运行 x64 安装器。当前无发行者签名，SmartScreen 可能提示未知发布者；确认来源与校验值后再继续。WebView2 离线安装器与所需运行资源随包提供。Windows 10、Windows ARM64、完全干净且缺少运行依赖的虚拟机尚未验证，不作为本次支持承诺。

Linux、手机 / 平板本版不提供。暂不提供自动更新；请手动安装后续版本。

## 开始之前

需要自行准备兼容 OpenAI 格式的模型 API 地址、密钥和模型名称（例如 DeepSeek 的 `deepseek-chat`）；模型服务可能收费。momo 没有内置聊天大模型。语音输出为可选功能，项目不分发默认角色参考音频；文字聊天不依赖 TTS 或 GPU 服务。

默认 Hiyori、字体、Cubism Core 和本地推理资源随包交付，各自遵循其许可，见[素材说明](https://github.com/Momoyeyu/momo/blob/v0.2.0/THIRD_PARTY_NOTICES.md)。

[初次见面与配置](https://momoyeyu.github.io/momo/help/getting-started) · [语音设置](https://momoyeyu.github.io/momo/help/voice) · [备份与迁移](https://momoyeyu.github.io/momo/help/data)

## 升级与数据

安装前请在「设置 → 通用 → 数据备份」导出副本；备份包含私人内容和服务密钥，请妥善保管。本次安装包不包含玩家数据，也不要求重置现有进度。替换应用时保留其数据目录；跨机器或从旧实验版本迁移使用导出 / 恢复，不直接覆盖数据库。

## 验证与边界

两个平台从同一源码提交构建，使用实际安装资源检查启动、模型连接、真实对话 / TTS / ASR、表情转场、记忆 / 存档、MCP、单实例与退出回收。原生自动化使用独立测试驱动构建，公开安装包不带测试入口。内置模型在安装资源上直接推理通过；这不等于完成整机断网或所有系统版本测试。

这是早期桌面体验版。模型响应与 thinking 能力取决于所选服务，音色效果取决于 TTS 与参考音；请勿将所有第三方模型视为已验证。使用前了解所选模型、语音与工具服务的数据处理与费用。
