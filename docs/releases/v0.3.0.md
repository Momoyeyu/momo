# momo v0.3.0 · Can you feel my heart?

这一版让 momo 从房间里的对话伙伴，走向持续记忆、多模态交流与桌面陪伴。

## 新增与改进

- **连续的相处与记忆**：后台静默压缩较早的上下文，保留最近对话；根据模型窗口调整预算。长期记忆支持查看、编辑与置顶，名字引导会带你认识记忆功能。
- **文字、图片和语音**：统一的多模态消息处理；chat 支持粘贴图片、发送前移除，手机与记录可以直接显示收到的图片。图片理解需要支持视觉的模型，语音识别资源随包提供。
- **QQ 与数字手机（macOS）**：插件内扫码登录、退出、启停和权限管理；手机展示应用、消息与处理过程。支持白名单、图片／表情、语音转录等；专注对话可以暂缓插件消息处理。
- **桌面陪伴（macOS）**：全身／半身取景、拖动、可折叠对话框、独立竖向工具栏与可恢复的鼠标穿透。观察和主动回应可直接控制；操作应用仍经过独立授权，已允许的应用可管理。
- **声音与氛围**：原创交互音效和可循环 BGM，按场景切换，支持通过对话控制音乐；独立音量与音效风格设置。房间背景随时段变化。
- **语音延迟优化**：增加 TTS 预热、复用与播放调度，减少首次发声等待；试听台词与标题 slogan 同步，支持中英日。
- **重新设计的首次引导**：语言、LLM、可跳过的 TTS 配置、认识用户、记忆置顶与完成庆祝；检查点可恢复，引导上下文与正常对话隔离。
- **界面与偏好**：命令行风格对话框和标题打字效果、手机方格转场、平衡的插件卡片与分页。用户选过的开关和档位会保留，包括取景、折叠、静音、专注和主动回应。
- **桌面运行时更新**：迁移至 Electron，复用同一套前后端；本地数据隔离、备份恢复、单实例和退出清理继续保留。

## 使用前

需要自行配置兼容 OpenAI 的模型 API；没有内置聊天大模型。视觉能力取决于模型 API，TTS 是可选服务，不分发私人参考音频或账号数据。Windows／Linux 的原生 QQ 与电脑操作适配尚未完成，不能视为与 macOS 全功能等同。

升级前请导出数据备份。v0.2 使用旧桌面壳；如新版本未自动读取旧数据，请使用导出／恢复，不手工覆盖数据库。备份含服务密钥与私人对话，请妥善保管。

本版暂未提供商业发行者签名或 Apple 公证。macOS 使用固定本机开发签名；下载者可能收到系统安全提示，不需要关闭系统全局安全保护。

## 下载与平台范围

| 平台 | 下载 | 使用方式 |
| --- | --- | --- |
| macOS Apple Silicon | `momo_0.3.0_macos_arm64.dmg` | 打开 DMG，将 momo 拖入 Applications；本版没有 Intel Mac 构建。 |
| Windows x64 | `momo_0.3.0_windows_x64.zip` | 解压整个目录后运行 `momo.exe`；便携发行包，不是安装器。 |
| Linux x64 | `momo_0.3.0_linux_x64.tar.gz` | 解压后在图形桌面运行 `./momo`；以 Linux Mint 22.3 / Ubuntu 24.04 系、glibc 2.39 环境构建验证，需要系统图形／音频运行库；旧发行版兼容性未验证。 |

三个包均自带 Python 后端、Node 插件运行时、默认角色、字体、语音识别和向量检索资源；无需 Docker。

macOS 提供原生 QQ、桌面观察与应用控制。Windows／Linux 暂不提供原生 QQ 和电脑控制，入口会明确禁用；Windows 的 Minecraft 适配也暂不支持。Linux 的 Minecraft 适配未在本轮做真实游戏联调，不列为已验证能力。平台差异不会通过无效按钮或启动报错隐藏。

下载后可用 `SHA256SUMS.txt` 检查完整性；`build-info.json` 记录构建来源、平台及验证范围。

## 本轮验证

- 三个平台均测试实际打包产物启动，标题／设置／chat、Live2D、设置保留和退出；对话 smoke 使用隔离的本地测试 provider，不消耗或分发用户 API 配置。
- Windows／Linux 冻结后端通过真实本地 ASR 与 embedding 推理、鉴权、中文数据路径及 EOF 退出；Linux UI 在 Xvfb 软件渲染环境验证，尚不代表各种桌面发行版／GPU 兼容性。
- macOS 额外覆盖桌宠、备份恢复和单实例；固定本机开发签名校验通过，已替换本机唯一安装版本。
- 两仓 CI 与 34 项 Electron 壳测试通过。本轮不重复真实 QQ 账号收发、应用输入和 Minecraft 游戏联调。
