# momo v0.3.1 · A little more momo

本次是 v0.3.0 的人物视觉与设计资料补丁。

## 更新

- momo 宣传剪影在鬓角加入品牌 logo 头饰；保留原有姿态、服装、构图与其余图像像素。
- 游戏标题、启动／ASCII 转场、手机壁纸、官网和 README 统一使用新版形象。
- 原创人物设定包公开保存于 `docs/character/`：正／侧／背及 3/4 多视图、表情与口型、服饰和配件细节。属于概念设计参考，不替换玩家当前的 Live2D。

## 下载与升级

- macOS Apple Silicon：`momo_0.3.1_macos_arm64.dmg`
- Windows x64：`momo_0.3.1_windows_x64.zip`
- Linux x64：`momo_0.3.1_linux_x64.tar.gz`

安装前建议导出备份。使用原数据目录，保留已有配置、记忆与存档。macOS 沿用固定本机开发签名，未提供 Apple 公证；Windows 为便携包。Linux 沿用 Ubuntu 24.04 / glibc 2.39 构建环境。

功能与平台边界沿用 [v0.3.0](v0.3.0.md)：QQ 和原生电脑观察／控制目前仅在 macOS 提供，Windows 的 Minecraft 适配暂不可用。未引入新的账号权限或默认模型服务。

`SHA256SUMS.txt` 用于核验下载，`build-info.json` 记录本轮构建来源与实际验证范围。

## 本轮验证

三端实际打包产物均完成基础启动、标题／设置／chat、Live2D、测试对话、偏好保留与退出检查；macOS 额外验证桌宠、单实例和备份恢复。macOS 备份恢复的前两次自动化运行等待重载超时，保留失败记录，加入焦点与对话框诊断后完整复测通过。Windows／Linux 冻结后端的本地 ASR、embedding 与鉴权检查通过；Linux 界面在 Xvfb 下测试，未覆盖实体 GPU 或所有发行版。

未重复真实 QQ 账号收发或 Minecraft 联调。平台能力不因这次视觉补丁扩大。
