# 012：产品官网独立迭代

状态：本地候选验证通过，准备发布后检查线上。官网从 006 的桌面迁移拆出，独立维护产品内容与静态站体验；macOS 应用验收及其他 PC 平台仍按各自计划推进。

## 决策

- 首页按初见、日常相处、记忆与存档、声音 / 形象 / 拓展、当前能力与愿景、入门问题展开。补足真实产品信息，避免用架构细节或重复截图撑长度。
- 沿用游戏墨紫 / 柔金 / 暖白的单一配色；共用抽象品牌、Nunito 与 Noto Sans SC / JP。导航提供语言切换与可访问 GitHub 图标，不提供日夜模式。
- 宣传正文提供中 / 英 / 日独立静态路径；中文 canonical 使用指南统一生成，其他语言入口明确标注指南语言。
- 保留真实无声片段与可拖动、键盘切换的叠放卡片。无公开安装包时如实显示候选状态，不伪造下载地址，不将长期自进化愿景宣传为现有功能。

## 数据与发布边界

非网站积压代码已独立审查。用户配置、密钥、记忆、存档、参考音、导入模型和测试产物被忽略；默认 Hiyori 的全部 21 个引用资源与许可进入源码。使用文档的本地链接检查无缺失目标。第三方来源文件保留原始字节及其校验值，不为清除上游文件末尾空行而改变许可 / 资源校验。

网站发布不等于公开发行安装包，不自动归档 momo-web 或删除 momo-infra；这些仍遵守用户验收边界。

## 本轮验证

- 4 项资源 / 帮助生成 / 字体许可 / 三语内容结构测试通过，静态构建通过。
- 桌面 4 个真实浏览器场景逐个通过：中文、英文、日文完整内容与 SSR 元信息；实际导航锚点后切换语言保持位置；语言菜单 Escape / 外部点击；帮助正文互链、刷新与返回；叠卡拖动 / 键盘、视频播放 / 暂停 / 离屏及站内链接。
- 依据真实失败修复了语言切换的旧链接读取时序，以及帮助正文互链丢失语言参数。独立复核未发现遗留阻断。
- 本次 macOS Chrome 155 在复用进程创建新 context 时出现系统级退出，发生在访问页面之前；因此 4 个场景分别用新进程验证，无增加重试或固定睡眠。保留失败与通过日志，不报告为一次合并运行全绿。
- 三语整页截图已人工查看。其他 PC 平台应用未重建，手机应用不在本次范围。
