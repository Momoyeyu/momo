# 010：macOS 启动剪影候选

状态：可体验，等待用户验收。Windows 兼容已从 006 拆至 011，Linux 可选，不做手机应用；本轮只更新和验证 macOS。

## 实现

- 本地 HTML / CSS / SVG 在 React、Live2D 之前出现：抽象纸影、缓慢呼吸与细线光点，沿用游戏的墨紫 / 金 / 暖白。
- 显示实际连接和恢复阶段，不造百分比、不额外预热模型、不等远端模型 / TTS、不人为凑时长。游戏提交后释放输入锁并短淡出；减少动态时直接切入。
- 错误时静止并提供重试；固定三语文案不展示原始异常。StrictMode 重复挂载不会重复移除或留下输入锁。
